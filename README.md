## Loadstring

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/tekkenbugatti/tekkenbugattis-Sticky-Jumper/main/StickyJumper.luau"))()
```

Needs an executor (the script uses `getgenv`, `writefile`/`readfile` etc.). Drop the line into your executor's `autoexec` folder if you want it to load on inject. The URL always serves the latest commit, so every push makes the loader pick up the new version automatically (no changes needed to the loadstring).

Quick start (manual): equip the **Sticky Jumper** tool, LMB = fire / RMB = detonate (while aiming), right-shift in first person opens the colour + canopy screen.
